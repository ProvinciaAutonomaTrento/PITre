# Package Pi3.Core.ElementAggregate
Il package definisce Element, l'aggregato astratto utilizzato come base per tutti gli aggregati presenti in PiTre. 

Definisce le seguenti caratteristiche comuni a tutti gli aggregati:
- Tenant
- Name
- Description
- CreationDate
- Keywords
- Profiles

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.ElementAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.ElementAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
