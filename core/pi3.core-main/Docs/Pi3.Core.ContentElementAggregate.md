# Package Pi3.Core.ContentElementAggregate
Il package definisce ContentElement, l'aggregato astratto che estende Element per aggiungere i seguenti attributi:
- Permissions
- RelatedElements

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.ContentElementAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.ContentElementAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
