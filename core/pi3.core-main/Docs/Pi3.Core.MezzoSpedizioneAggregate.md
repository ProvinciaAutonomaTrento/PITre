# Package Pi3.Core.MezzoSpedizioneAggregate
Il package definisce l'aggregato MezzoSpedizione per gestire i mezzi di spedizione utilizzati dai documenti ammministrativi protocollati in entrata.

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.MezzoSpedizioneAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.MezzoSpedizioneAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
