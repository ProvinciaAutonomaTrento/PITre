# Package Pi3.Core.AggregazioneDocumentaleAggregate
Il package  definisce l'aggregato AggregazioneDocumentale secondo le specifiche definite nelle linee guida [AGID](https://www.agid.gov.it/sites/default/files/repository_files/allegato_5_metadati.pdf).

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.AggregazioneDocumentaleAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.AggregazioneDocumentaleAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
