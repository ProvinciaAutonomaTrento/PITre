# Package Pi3.Core.TrasmissioneAggregate
Il package definisce l'aggregato Trasmissione per gestire i flussi documentali verso utenti o gruppi destinatari interni all'ogranigramma PiTre.

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.TrasmissioneAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.TrasmissioneAggregate
```
## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
