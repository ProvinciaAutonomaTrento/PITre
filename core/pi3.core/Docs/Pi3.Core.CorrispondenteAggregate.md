# Package Pi3.Core.CorrispondenteAggregate
Il package definisce l'aggregato astratto Corrispondente come base per gestire i corrispondenti esterni all'organigramma PiTre.

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.CorrispondenteAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.CorrispondenteAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
