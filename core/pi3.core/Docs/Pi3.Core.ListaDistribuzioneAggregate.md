# Package Pi3.Core.ListaDistribuzioneAggregate
Il package definisce l'aggregato ListaDistribuzione il quale permette di definire, attribuendogli un nome, un soggetto aggregante per corrispondenti di tipo persona, gruppo o ufficio. Tali soggetti possono essere utilizzati come destinatari per trasmissioni di documenti amministrativi o aggregazioni documentali.

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.ListaDistribuzioneAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.ListaDistribuzioneAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
