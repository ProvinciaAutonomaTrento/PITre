# Package Pi3.DocumentBlobAggregate
Il package  definisce l'aggregato DocumentoBlob per gestire il contenuto binario di un file presente nel sistema documentale.

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.DocumentBlobAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.DocumentBlobAggregate
```
## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
