# Package Pi3.Core.RagioneTrasmissioneAggregate
Il package definisce l'aggregato RagioneTrasmissione per amministrare le ragioni utilizzate per trasmettere documenti amministrativi o aggregazioni documentali.

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.RagioneTrasmissioneAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.RagioneTrasmissioneAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
