# Package Pi3.Core.OggettoAggregate
Il package definisce l'aggregato Oggetto per gestire l'anagrafica dell'oggettario. Gli oggetti sono utilizzabili nei documenti amministrativi e aggregazioni documentali.

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.OggettoAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.OggettoAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
