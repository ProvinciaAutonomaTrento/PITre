# Package Pi3.Core.DelegaAggregate
Il package definisce l'aggregato Delega per gestire le sostituzioni.

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.DelegaAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.DelegaAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
