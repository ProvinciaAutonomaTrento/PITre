# Package Pi3.Core.DocumentAggregate
Il package include l'aggregato Document che, estendendo ContentElement, definisce il documento generico nel sistema documentale. 
Non rappresenta la definizione di documento amministrativo informatico, che è invece definito in [Pi3.Core.DocumentoAmministrativoAggregate](/Docs/DocumentoAmministrativoAggregate.md).

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.DocumentAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.DocumentAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
