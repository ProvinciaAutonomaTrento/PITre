# Package Pi3.Core.PersonaCorrispondenteAggregate
Il package definisce l'aggregato PersonaCorrispondente il quale permette la gestione di un corrispondente esterno all'organigramma PiTre di tipo persona fisica.

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.PersonaCorrispondenteAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.PersonaCorrispondenteAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
