# Package Pi3.Core.NotaRFAggregate
Il package definisce l'aggregato NotaRF per la gestione completa dell'anagrafica delle note associate agli RF. Tali note sono a loro volta inserite nelle Note dei documenti amministrativi e aggregazioni documentali.

## Installa il package

Installa il package tramite NuGet Package Manager:

```
Install-Package Pi3.Core.NotaRFAggregate
```

Oppure tramite l'interfaccia della riga di comando di .NET Core:

```
dotnet add package Pi3.Core.NotaRFAggregate
```

## Linguaggio, piattaforma e tool di sviluppo
C# 10, .NET 6, Visual Studio 2022.
